# Contoh Skill

Ini contoh format. Ganti isinya atau hapus kalau ga dipakai.

Nama file = nama skill. `contoh.md` dipanggil dengan `read_skill({ name: "contoh" })`.

## Kapan dipakai

Tulis kondisi singkat kapan skill ini relevan.

## Langkah

1. Langkah pertama.
2. Langkah kedua.

## Batasan

Hal yang tidak boleh dilakukan saat menjalankan skill ini.
